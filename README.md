# Mahle
**Industrial IoT Machine Monitoring Dashboard** 
| React.js, JavaScript, MQTT

A real-time Industrial IoT monitoring dashboard developed using React.js, HTML, CSS, JavaScript, and MQTT. The application integrates machine simulators with an MQTT broker to enable live machine data visualization, performance monitoring, OEE tracking, and industrial process analysis. It supports MQTT-based publish/subscribe communication, MQTTX testing, and interactive dashboards for monitoring machine status, workcenters, and materials.
